# 동시 요청 간 공유 GP 실험 (사전 등록)

작성 2026-10-16. **이 문서와 실행 스크립트 `PartB/training/shared_gp.py`를 커밋한 뒤에** 한 번만 실행한다. 결과가 어떻게 나와도 그대로 보고한다. 논문 1차 제출본(10/17)과 무관한 후속 연구이며, 동결된 숫자·그림은 바꾸지 않는다.

## 1. 배경과 공개 사항

- 한 경로 안에서는 GP가 단순 규칙을 이기지 못했다(지점 중앙 규칙 우세, 적응형 예산 사전 등록 실험 불통과 — findings §32.29).
- 여기서는 단순 규칙이 못 하는 일, 곧 **같은 10분 캐시 창 안의 다른 승객 요청이 이미 조회한 셀의 정보를 빌려 오는 일**을 GP에 맡긴다.
- 2026-10-16에 **검증 분할만** 써서 가능성을 탐색했다(스크립트 `docs/plan/shared_feas.py`, 결과 `results/shared_gp_feas/summary.json`, findings §32.30). 결과: §7. 테스트 분할과 새 기간 자료는 이 방법에 한 번도 쓰지 않았다.
- 탐색 중 비GP 비교 규칙(N)의 격자를 한 번 넓혔다(GP가 약한 비교 대상 덕에 이기지 않도록). GP 쪽은 바꾸지 않았다.

## 2. 설정 (고정)

- **셀 조회 = 그 셀의 시간별 전체 계열**(oracle.py). 그래서 캐시된 셀은 창 안의 모든 시각에서 정확히 알려진다. 공유 GP는 82개 셀 중심 위의 **공간 크리깅**이고, 각 경로 지점의 도착 시각에서 캐시된 셀들의 같은 시각 값으로 예측한다(시간 축은 캐시된 셀에 새 정보를 주지 않음).
- 공간 GP: Matérn ν = 0.5, log1p, 상수 평균 = 캐시된 셀 z의 평균(plug-in). 초매개변수는 **학습 분할** 우천 시간 600개(seed 20261016)로 적합한 값으로 고정: σ_f = 0.2766, σ_n ≈ 0, 길이 척도 23.32 km(이웃 셀 상관 0.68).
- 요청 흐름: 우천 시간(현지 06–23시, 어떤 셀이든 0.1mm 초과) 중 무작위 300개, 각 시간의 무작위 분에서 시작하는 10분 창. 창마다 N건의 요청이 고르게 도착하고, 경로는 본 실험 400개 경로에서 균등 추출. 창 시작 때 캐시는 비어 있다(T3 캐시 가정과 같음). seed = (20261017, N).
- 오차 대상: 창 안의 MAIN 유형 요청(U ≥ 3, 0.1mm 초과 지점 있음). 호출 수는 창 안 모든 요청 기준 요청당 평균.

## 3. 방법 (고정)

| 이름 | 절차 |
| --- | --- |
| **G. 공유 GP** | 창의 첫 요청은 지점 중앙 셀 1개를 먼저 조회. 이후 캐시된 모든 셀로 경로의 미조회 셀을 크리깅하고, 경로 평균(mm/h)의 델타법 표준편차가 τ보다 작아질 때까지 \|g\|·sd가 가장 큰 셀을 하나씩 조회 |
| **N. 비GP 이웃 규칙** | 지점 중앙 셀부터 경로 순서로: 캐시에 있으면 그대로, 없으면 반경 r km 안 캐시 셀들의 값 범위(지점 시각별 최대−최소)가 d 미만일 때 역거리제곱 평균을 복사, 아니면 조회 |
| **P. 고정 예산 + 캐시** | 지점 중앙 규칙 k = budget(U, ρ)로 조회(캐시 적중은 무료), 선택 셀과 이미 캐시된 경로 셀로 동결 GP(경로 축) 보간 |
| **F. 전체 캐시** | 경로의 미캐시 셀을 모두 조회(오차 0). 호출 수 기준선으로만 보고 |

### 매개변수 선택 (검증 분할만, 스크립트가 자동으로)

- N = 20, 목표 호출 = 검증에서 F의 요청당 호출 × 0.5 × 0.97.
- τ: 0.005~0.500(0.005 간격) 중 호출이 목표 이하인 값 가운데 호출이 가장 많은 값.
- N: r ∈ {9.5, 13, 19, 27} km × d ∈ {0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1, 2} mm/h 중 호출이 목표 이하이고 검증 MAE가 가장 작은 값.
- P: ρ ∈ {0.05, …, 1.00} 중 같은 기준. 목표 이하가 없으면 호출이 가장 적은 값(표시).

## 4. 평가 자료

1. **새 기간(주 평가)**: 2025-12-01~2026-10-14 셀 자료(docs/temporal-check.md에서 이미 받은 원자료, SHA-256 기록)의 우천 시간.
2. **MAIN 테스트 주(보조)**: 본 실험 기간 중 테스트 분할 주의 우천 시간.

## 5. 검정

| 이름 | 비교 | 자료 |
| --- | --- | --- |
| S1-b | G − N 창 평균 절대 오차 | 새 기간 (주) |
| S2-b | G − P 창 평균 절대 오차 | 새 기간 (주) |
| S1-a, S2-a | 같은 비교 | MAIN 테스트 주 (보조) |

- 분석 단위는 **창**(같은 창의 요청은 날씨를 공유하므로 서로 독립이 아님). 양측 Wilcoxon 부호순위, 주 검정 2개에 Holm. 평균 차이 95% 구간은 ISO 주 블록 부트스트랩(B = 2000, seed 42).

## 6. 판정 (결과 전에 정함)

**통과** = 다음을 모두 만족.
- S1-b·S2-b: Holm p < 0.05, 평균 차이 < 0(G의 오차가 작음), 새 기간에서 G의 요청당 호출이 비교 대상의 1.05배 이하.
- S1-a·S2-a: 평균 차이 < 0, 호출 1.05배 이하.

하나라도 어기면 불통과로 보고한다. 통과해도 1차 제출 논문은 바꾸지 않고, 후속 연구·발표 자료에 쓴다.

기술 통계(검정 없음): N = 20에서 목표 비율 0.25·0.75, 그리고 N = 5·10·50에서 비율 0.5의 호출·MAE·할증 판단 일치율(각 설정을 검증에서 다시 선택).

## 7. 가능성 탐색 결과 (검증 분할, 300개 창)

MAIN 유형 요청의 경로 평균 MAE(mm/h). 비교 규칙 값은 각 규칙 매개변수 격자의 오차–호출 하한선을 G와 같은 호출 수에서 선형 보간한 값(검증 자료로 고른 최선이라 비교 규칙에 유리하다).

| 10 | 2.28 | 0.96 (42%) | 0.046 | 0.067 | — | 1.27 (56%) | 0.028 | 0.057 | 0.068 |
| 20 | 1.61 | 0.69 (43%) | 0.041 | 0.056 | — | 0.92 (57%) | 0.024 | 0.041 | 0.073 |
| 50 | 0.92 | 0.40 (43%) | 0.035 | 0.039 | — | 0.53 (57%) | 0.021 | 0.024 | 0.068 |

(— = P는 k ≥ 1이라 그만큼 호출을 줄일 수 없음.) 미리 정한 "가능성 있음" 기준(어떤 N에서 같은 호출의 G MAE가 N 규칙과 P 모두보다 10% 이상 낮고 이웃 N에서도 같은 방향)을 N = 5·10·20에서 만족했다. N = 50에서는 차이가 8~13%로 줄었다(요청이 많으면 이웃이 거의 다 캐시되어 단순 복사도 잘 맞음). 관측값을 쓰지 않는 GP 규칙(셀별 사후 sd만으로 조회, "GP-cell")은 N 규칙보다 나빴다. 즉 이득은 GP 분산 자체가 아니라 **크리깅 예측 + 값에 따라 달라지는 경로 평균 불확실성**에서 온다.
