# 시간 보류 확인 실험 (사전 등록)

작성 2026-10-16. **이 문서를 커밋한 뒤에** 데이터를 내려받고 실험을 한 번만 돌린다. 결과가 어떻게 나와도 그대로 보고한다.

## 1. 왜 하는가

본 실험(태그 `v1.0-paper`)의 자료는 2022-06-01~2025-11-30이다. 다음 두 결과는 이 기간에서만 확인됐다.

- **지점 중앙 규칙(H-P, 논문의 Mid)이 사후 분산 배치(M2)보다 오차가 작다.** 이 규칙은 테스트를 연 뒤에 만들었다(사후 분석, findings §32.2).
- M2가 균등 지점 조회(B1)보다 오차가 작다.

모델을 고정한 뒤의 **새 기간**(2025-12-01~2026-10-14, 2026년 남서 몬순 포함)에서, 미리 정한 검정으로 두 결과가 다시 나오는지 확인한다. 이 기간의 자료는 모델 학습·설정 선택·사후 분석 어디에도 쓰이지 않았다.

## 2. 고정하는 것

| 항목 | 값 |
| --- | --- |
| 기상 자료 | Open-Meteo Historical Weather API, `models=ecmwf_ifs`, 본 실험과 같은 격자 셀 82개(`PartB/data/grid_cells.json`), 2025-12-01~2026-10-14(UTC), 시간별 precipitation |
| 경로 | 본 실험과 같은 `routes.parquet`(400개)와 `routes_holdout.parquet`(100개). 새로 만들지 않는다 |
| 대상 경로 | 지나는 셀 U ≥ 3인 경로 |
| 출발 시각 후보 | 새 기간의 현지 시각(IST) 06:00~23:00 정시 |
| 우천 표본 | 도착 시각 기준 강수(본 실험과 같은 시간 선형 보간)가 0.1mm/h를 넘는 지점이 하나라도 있는 출발 시각 |
| 표본 추출 | 경로마다 우천 출발 시각 4개를 비복원 무작위 추출(`numpy.random.default_rng(20261016)`, 경로 순서는 route_set, route_id 정렬). 4개 미만이면 전부 쓴다 |
| 모델 | `PartB/configs/model_a_frozen.json`의 동결 GP. 다시 학습하지 않는다 |
| 방법 | B1, M1, M2, H-P. 본 실험 코드(`training.posthoc_placement.predict`)를 그대로 쓴다 |
| 예산 | k/U = 0.25, 0.5, 0.75(본 실험과 같은 반올림) |
| 지표 | 표본별 경로 평균 강수 절대 오차 \|m̂ − m\| |

## 3. 검정 (주 검정 2개)

| 이름 | 비교 | 예산 | 지지 조건 |
| --- | --- | --- | --- |
| T-1 | M2 − H-P | k/U = 0.5 | 양측 Wilcoxon 부호순위 검정, Holm 보정 p < 0.05, 평균 차이 > 0 |
| T-2 | B1 − M2 | k/U = 0.5 | 같음 |

- Holm 보정은 T-1, T-2 두 개에만 적용한다.
- 평균 차이의 95% 구간은 ISO 주 단위 블록 부트스트랩(B = 2000, seed 42)으로 구한다.
- 검정 함수는 본 실험과 같은 `wilcoxon_pair`, `holm`, `week_bootstrap_ci`를 쓴다.
- k/U = 0.25, 0.75와 M1은 검정 없이 MAE와 구간만 기술한다.

## 4. 논문에 쓸 문장 (결과 전에 정함)

- **T-1 지지**: "모델 고정 뒤 기간(2025-12~2026-10, n = …)에서 미리 정한 검정으로도 지점 중앙 규칙이 M2보다 작았다(… 대 …mm/h, Holm 보정 p = …)."
- **T-1 기각**: "모델 고정 뒤 기간에서는 지점 중앙 규칙과 M2의 차이가 확인되지 않았다(… 대 …mm/h, p = …)." 이 경우 사후 규칙에 관한 서술의 강도를 낮춘다.
- T-2도 같은 방식으로 쓴다.
- 어느 경우든 새 표본 수, 기간, 사전 등록 사실을 함께 적는다.
