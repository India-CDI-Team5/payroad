# 실시간 예보 전향 확인 실험 (사전 등록)

작성 2026-10-17. **이 문서와 `PartB/training/realtime_collect.py`, `PartB/training/realtime_check.py`를 커밋한 뒤** 분석 창의 예보를 모으고, 2026-11-18 이후 평가를 **한 번만** 한다. 결과가 어떻게 나와도 그대로 보고한다.

## 1. 왜 하는가

지금까지의 배치 비교는 과거 분석 자료(본 실험·시간 보류 확인)와 **1일 전 예보**(docs/forecast-check.md, F-1·F-2 지지)에서 했다. 서비스는 출발 시각에 그때의 최신 예보(선행 0~2시간)를 받는다. 이 조건을 그대로 재현한 자료로, 결과를 보기 전에 정한 검정을 다시 한다. 자료는 앞으로 수집하므로 어떤 설정 선택·사후 분석에도 쓰인 적이 없다(전향적).

## 2. 고정하는 것

| 항목 | 값 |
| --- | --- |
| 수집 | `realtime_collect.py`를 Windows 작업 스케줄러로 매시 실행. Open-Meteo Forecast API, `models=ecmwf_ifs`(서비스 MODEL), hourly precipitation, forecast_days=2(서비스와 같음), UTC, 격자 셀 82개(`grid_cells.json`) 한 번의 다중 좌표 요청. 반환 좌표가 셀과 0.01° 안인지 확인 |
| 분석 창 | 수집 시각 2026-10-18T00:00Z 이상 2026-11-18T00:00Z 미만, 그중 수집 시각이 IST 06:00~23:59인 스냅숏. 이 문서 커밋 전에 받은 시험 스냅숏은 쓰지 않는다 |
| 결측 | PC가 꺼져 있거나 요청이 실패한 시각은 빠진다(수집 여부는 날씨와 무관). 빠진 시각을 다시 받지 않는다 |
| 출발 | 스냅숏 수집 시각 T에 출발(선행 0, 서비스 조건). 각 지점 값은 같은 스냅숏에서 도착 시각으로 선형 보간 |
| 경로 | 본 실험의 `routes.parquet`(400개)·`routes_holdout.parquet`(100개) 중 U ≥ 3 |
| 우천 표본 | 0.1mm/h를 넘는 지점이 하나라도 있는 (스냅숏, 경로). 스냅숏마다 최대 4개를 비복원 무작위 추출(`default_rng(20261118)`, 경로 순서는 (route_set, route_id) 정렬) |
| 참값 | 같은 스냅숏의 전수 조회 경로 평균 |
| 모델·방법·예산 | 동결 GP, B1·M1·M2·H-P(논문의 Mid), k/U = 0.25·0.5·0.75 — `training.temporal_check.evaluate` 그대로 |

## 3. 검정

| 이름 | 비교 | 예산 | 지지 조건 |
| --- | --- | --- | --- |
| R-1 | M2 − H-P | k/U = 0.5 | 양측 Wilcoxon 부호순위, Holm 보정 p < 0.05, 평균 차이 > 0 |
| R-2 | B1 − M2 | k/U = 0.5 | 같음 |

- Holm 보정은 R-1, R-2에만. 평균 차이 95% 구간은 **IST 날짜** 블록 부트스트랩(B = 2000, seed 42; 기간이 5주 안팎이라 주 대신 일).
- 우천 표본이 **200개 미만**이면 검정하지 않고 MAE와 구간만 기술한다.

## 4. 결과 문장 (결과 전에 정함)

- **둘 다 지지**: "서비스와 같은 조건의 실시간 예보(2026.10.18~11.17, n = …)에서도 미리 정한 검정으로 지점 중앙 규칙이 M2보다, M2가 B1보다 오차가 작았다(… 대 … 대 …mm/h, Holm p …)."
- **기각**: 기각된 비교를 그대로 적고, 해당 결론을 "분석 자료·1일 전 예보에서"로 한정한다.
- **200개 미만**: "수집 기간의 우천 표본이 …개로 사전에 정한 최소 표본에 못 미쳐 기술 통계만 보고한다."
- 발표(2차 심사)와 이후 원고에 쓰며, 1차 제출 원고(2026-10-19)에는 들어가지 않는다.

## 5. 코드 확인

평가 코드 점검은 `realtime_check.py --smoke`로만 한다. 분석 창 **이전** 스냅숏(커밋 전 시험 수집분)만 쓰고, 표본 수와 행 수만 출력한다.
