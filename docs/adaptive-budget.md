# GP 불확실성 기반 적응형 예산 실험 (사전 등록)

작성 2026-10-16, 개정 2026-10-16(실행 전, §8). **이 문서와 실행 스크립트 `PartB/training/adaptive_budget.py`를 커밋한 뒤에** 한 번만 실행한다. 결과가 어떻게 나와도 그대로 보고한다.

## 1. 배경과 공개 사항

- 본 실험과 사후 분석에서 GP 사후 분산은 **조회 위치**를 정할 때 관측값과 무관한 기하 점수였고, 단순 계통 표집(지점 중앙 규칙)이 더 나았다.
- 2026-10-16에 **검증 분할만** 써서 탐색했다(paper/findings §32.28, 스크립트 docs/plan/feas.py, seq.py). 관측값을 반영한 위치 점수는 이득이 없었다. 반면 첫 셀 조회 뒤 **GP 경로 평균 불확실성으로 조회 개수를 경로마다 정하는 규칙**은 같은 호출 수에서 고정 예산 규칙과 비GP 적응 규칙보다 오차가 낮았다.
- 이 탐색은 검증 분할에서만 했다. 테스트 분할과 새 기간 자료로 이 방법을 평가한 적은 없다.

## 2. 방법 (고정)

모든 방법은 같은 동결 GP(`model_a_frozen.json`, Matérn ν = 0.5, log1p, κ = 2.2)로 보간한다.

| 이름 | 절차 |
| --- | --- |
| **A. GP 적응형 예산** | ① 지점 중앙 규칙으로 셀 1개 조회. ② 그 셀의 모든 지점 강수가 0이면 멈춘다. ③ 아니면 남은 셀 중 식 (3) 점수(지점 사후 분산 합, M2와 같은 점수)가 가장 큰 셀을 하나씩 더 조회하고, 매번 GP 사후 표본 200개(seed = DRAW_SEED + sample_id)로 구한 경로 평균의 표준편차가 τ보다 작으면 멈춘다. 모든 셀을 조회하면 멈춘다 |
| **B. 고정 예산(지점 중앙)** | 지점 중앙 규칙, k = round(0.5U)(본 실험의 예산 규칙) |
| **C. 비GP 적응형 예산** | A의 ①②와 같은 순서로 조회하되, 멈춤을 관측 셀 평균만으로 정한다. 후보 두 계열: 관측 셀 평균의 범위 < d(셀 2개 이상일 때), 관측 셀 평균의 평균 < t |

### 매개변수 선택 (검증 분할만, 실행 스크립트가 자동으로)

- 검증 대상: 검증 분할(split = val) 중 U ≥ 3이고 0.1mm/h 초과 지점이 있는 표본(주 분석 MAIN과 같은 정의).
- 목표 호출 수 = 검증 대상에서 B의 경로당 평균 호출 수 × 0.97(평가 자료의 분포 차이로 A·C의 호출이 늘어날 여유).
- **τ**: 격자 0.005~0.300(0.005 간격) 중 평균 호출 수가 목표 이하인 값 가운데 평균 호출이 가장 많은 값.
- **C**: d 격자 0.01~1.00(0.01 간격), t 격자 0.01~2.00(0.01 간격) 각각에서 평균 호출 수가 목표 이하인 값 가운데 MAE가 가장 작은 값을 고르고, 두 계열 중 검증 MAE가 작은 쪽을 C로 쓴다.

## 3. 평가 자료

1. **새 기간(주 평가)**: 시간 보류 확인 실험(docs/temporal-check.md)의 우천 표본 1,512개(2025-12-01~2026-10-14, 같은 추출 규칙으로 재구성). 이 방법의 설계·탐색에 한 번도 쓰지 않은 자료다.
2. **MAIN 테스트(보조 평가)**: 본 실험의 우천 테스트 표본 491개(U ≥ 3). 이 방법을 설계하기 전에 다른 방법의 결과를 이미 본 자료라 보조로 둔다.

## 4. 검정 (주 검정 2개, 보조 2개)

| 이름 | 비교 | 자료 |
| --- | --- | --- |
| H1-a | A − B 절대 오차 | MAIN 테스트 |
| H1-b | A − B 절대 오차 | 새 기간 |
| H2-a | A − C 절대 오차 | MAIN 테스트 |
| H2-b | A − C 절대 오차 | 새 기간 |

- 주 검정은 H1-b·H2-b(새 기간). 양측 Wilcoxon 부호순위 검정, 이 2개에 Holm 보정. H1-a·H2-a(MAIN)는 같은 검정을 보조로 보고한다(보정 없는 p와 함께). 평균 차이 95% 구간은 ISO 주 블록 부트스트랩(B = 2000, seed 42).
- 강건성(보고만): 경로별·주별 평균으로 같은 검정.

## 5. 논문 반영 판정 (결과 전에 정함)

**다음을 모두 만족할 때만** 논문에 반영한다.
- 주 검정 H1-b·H2-b: Holm 보정 p < 0.05이고 평균 차이 < 0(A의 오차가 작음), 새 기간에서 A의 평균 호출 수가 비교 대상의 1.05배 이하
- 보조 H1-a·H2-a: 평균 차이 < 0(방향 일치), MAIN에서 A의 평균 호출 수가 비교 대상의 1.05배 이하

하나라도 만족하지 않으면 논문에 넣지 않고, 결과는 findings와 발표 자료에만 쓴다.

## 6. 반영할 때 쓸 문장 (결과 전에 정함)

"첫 셀을 조회한 뒤 GP 경로 평균의 불확실성이 기준보다 작아질 때까지만 셀을 더하는 적응형 예산은, 같은 평균 호출에서 고정 예산 지점 중앙 규칙보다 오차를 …%, 관측값만 쓰는 적응 규칙보다 …% 줄였다(사전 등록, MAIN 테스트·새 기간 모두 Holm p < 0.05)."

## 7. 기술 통계 (검정 없음, 보고만)

- **오차–호출 곡선**: B의 예산 비율 0.25·0.5·0.75 각각을 목표로(× 0.97) τ와 C를 검증에서 다시 골라, 두 평가 자료에서 A·B·C의 평균 호출과 MAE를 보고한다(발표 그림용). 목표 이하로 내려갈 수 없는 예산에서는 호출이 가장 적은 설정을 쓰고 표시한다.
- **할증 판단**: 예산 비율 0.5 설정에서 A·B·C의 할증 판단(β(r, 0) > 1.2, 즉 r > 4/3) Cohen κ(전수 조회 대비).
- **습윤 첫 셀 부분집합**: 첫 셀에 비가 있었던 표본만의 A 대 C 오차(건조 즉시 정지의 몫을 뺀 GP 정지 규칙의 몫).
