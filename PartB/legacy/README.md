# legacy

`match_result.csv` — 904 matches exported from the old Part A simulation (surge-only fares,
no bargaining). The retired XGBoost fare model was trained on it, and its target was a closed
formula of its own inputs (refactoring report v3, P0-1). Kept only as a reference for that
finding; **nothing in the current pipeline reads it and it must not be used for training.**
